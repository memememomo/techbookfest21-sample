# nesasm

デモ ROM（`roms/src/*.asm`）を、マッパー 0（NROM）の `.nes` にするアセンブラです。

```console
$ cd nesasm
$ cargo run --release -- 入力.asm 出力.nes --chr タイル.chr --pad FF --vertical
```

| オプション | 意味 |
|------------|------|
| `--chr PATH` | 8 KiB の CHR のファイル（省略すると、すべて 0） |
| `--pad HEX` | PRG ROM が 16 KiB に足りないときに埋める値（省略すると `EA`、つまり NOP） |
| `--vertical` | 垂直ミラーリングにする（省略すると水平） |
| `-h`, `--help` | 使い方を表示する |

`.org $C000` から書いたプログラムは、16 KiB の PRG ROM になります（`$8000`〜`$BFFF` にも、同じ内容が見えます）。

## 書き方

| 書き方 | 例 | 意味 |
|--------|----|------|
| 命令 | `lda #$10`、`sta $2000`、`lda table,x`、`lda (ptr),y`、`jmp (vector)` | 6502 の命令（大文字でも小文字でもよい） |
| ラベル | `reset:` | その場所のアドレスに名前を付ける。後ろで定義したラベルも使える |
| 定数 | `PPUCTRL = $2000` | 値に名前を付ける |
| 数 | `$FF`、`%1010`、`0x1F`、`10`、`'A'` | 16 進、2 進、16 進、10 進、文字コード |
| 式 | `table+1`、`period_lo-1`、`<label`、`>label` | `+ - * /` と括弧。`<` は下位バイト、`>` は上位バイト |
| `.org 式` | `.org $C000` | ここから先を置くアドレス |
| `.byte` / `.db` | `.byte $0F, $30, "TEXT", 0` | バイトを並べる（文字列も書ける） |
| `.word` / `.dw` | `.word nmi, reset, irq` | 2 バイトの値を並べる（下位バイトが先） |
| コメント | `; 説明` | `;` から行の終わりまで |

オペランドが 256 より小さいときはゼロページのモード（2 バイト）になります。`$0010` のように 3 桁以上の 16 進数で書いたときと、後ろで定義するラベルを使ったときは、絶対アドレスのモード（3 バイト）になります。
