# ROM ビューアー

デモ ROM（hello.nes、game.nes）を動かしながら、PPU の中身を絵と表で見るためのツールです。
第 12 章を終えた時点の mynes（`../ch12`）をそのまま使います。

- **パターンテーブル**（$0000〜$1FFF）: 256 個 × 2 枚のタイル。タイルを選ぶと、16 バイトのデータ（下位ビットと上位ビット）が 8 × 8 ドットの色番号になる様子を表示します
- **ネームテーブルと属性テーブル**（$2000〜$2FFF）: 4 枚分を並べて表示します。ミラーリングでどれが同じ中身になるか、画面に出しているのはどれかがわかります。タイルにマウスを乗せると、ネームテーブルのアドレス → タイル番号、属性テーブルのアドレス → 2 ビット → パレット番号、と色が決まるまでをたどれます
- **パレット**（$3F00〜$3F1F）: 背景用 4 組とスプライト用 4 組
- **OAM**: 64 個のスプライトの Y・タイル・属性・X と、その意味（1 ラインに 9 個以上並んで消えるものも）
- **PPUCTRL・PPUMASK** と、ROM の情報（割り込みベクタなど）

画面のタイルやスプライトにマウスを乗せると、ネームテーブル・パターンテーブル・OAM の該当する場所も強調されます。
一時停止と 1 フレームずつのコマ送りもできます。音は鳴りません。

## 動かし方

第 9 章と同じく、wasm-pack を使います。

```console
$ rustup target add wasm32-unknown-unknown
$ cargo install wasm-pack
$ cd viewer
$ wasm-pack build --target web --out-dir web/pkg
$ python3 -m http.server 8000
```

ブラウザで http://localhost:8000/web/ を開き、「hello.nes」か「game.nes」のボタンを押します。
（`viewer/roms/` からデモ ROM を読み込むので、サーバーは `viewer` ディレクトリで起動してください。）
自分で作った ROM は「ほかの ROM…」から選べます。

## しくみ

mynes の PPU は、ネームテーブルやパレットを外から読めるようにしていません。
そこでこのビューアーは、CPU と NesBus の間に見張り役のバス（`src/shadow.rs` の `WatchBus`）をはさみ、
CPU が PPU のレジスタ（$2000〜$2007）に書き込んだ内容を手元に写し取っています。
mynes のコードには手を入れていません。

`cargo test` で、写し取ったネームテーブルから描いた絵が、mynes の描いた画面と 1 ドットも違わないことを確かめています。
